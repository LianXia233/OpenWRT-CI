CORE ARCHITECTURE

核心系统方案与插件矩阵

精细化功能分层设计，确保不同使用场景下的极致稳定性与拓展能力。

NetWiz 网络向导与三层守护

新手友好的一站式配网流程。内置 netwiz-monitor 周期巡检、netwiz-recovery 智能自愈与 netwiz-watchdog 看门狗守护。断网、误删基础组件时自动触发离线保险箱自愈。

5G 模组控制 (MT5700 / FM350)

方案 B (MT5700) 基于 Rust musl 静态二进制后端，轻量不占内存；FM350 采用纯净 RNDIS 数据通道无内核冲突。支持实时 5G 信号（RSRP/RSRQ/SINR）、锁频锁小区与高速拨号。

多网络智能切换 (NetMode)

内置 luci-app-h5000m-netmode。支持「仅 5G 蜂窝」「仅 WAN 有线」「双链路负载均衡 / 主备毫秒级切流」。联动 mwan3 探针，遇到主线路网络故障瞬间切流，不断网。

硬件加解密与零配置组网

内核级预置 kmod-cryptodev 与 kmod-tls，代理隧道直接跑在芯片硬件加速引擎上。同时集成 Tailscale 与 EasyTier，即使无公网 IP 也能实现高速安全的异地内网穿透。
